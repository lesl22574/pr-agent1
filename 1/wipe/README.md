# Занятие «Вытри букву»

Это часть общей игры. Запуск: `../index.html` (файл `1/index.html` от корня репозитория).
В общем меню выберите «Рисование букв», затем «Играть».
Кнопка с домиком возвращает в общее меню.

В комплекте пары изображений для А, Б и В. Это самостоятельный режим,
который запускается только из общего меню. После шариков изучение букв
продолжается без перехода в рисование. Кнопка звука в рисовании скрыта.
При отдельном выборе занятия кнопка «Дальше» выбирает А, Б или В:
с галочкой «Вкусности» — по порядку, без неё — случайно без повтора предыдущей буквы.

`scene.html` — внутренняя сцена, которую общий запуск открывает в iframe:
так Canvas и стили двух частей остаются независимыми.

## Как подставить свои ассеты

1. Положите пару файлов в `assets/letters/`: `<slug>_foam.png` и
   `<slug>_clean.png`. Требования: одинаковый размер обеих картинок пары,
   прозрачный фон, буква в одном и том же месте кадра (слои должны
   совпадать пиксель в пиксель — тогда стирание выглядит идеально).
   Пропорции любые — игра сохраняет соотношение сторон спрайта.
   Пена может быть полупрозрачной (как в комплекте буквы «А»): сквозь неё
   проступает чистая буква, получая эффект «намыленной» поверхности.
2. Добавьте строку в `js/letters.js`:
   `{ char: 'Г', foam: 'assets/letters/g_foam.png', clean: 'assets/letters/g_clean.png', eyeNX: 0.5, eyeNY: 0.1 },`
   опционально поле `next: 'url/{char}'` — переход после полной очистки
   именно этой буквы (см. раздел про событие ниже).
3. Готово: игра подхватит букву в общей очереди «Дальше».

Свои `bg.png`, `towel.png` просто заменяются файлами с теми же
именами (пропорции любые — фон тянется на всю сцену 1280×720).

Демо-ассеты пересоздаются командой `python3 scripts/make_assets.py`
(нужен Pillow); список букв — в константе `CHARS` в начале скрипта.

## Настройка геймплея

Все ключевые числа — в объекте `CFG` в начале `js/game.js`:

| Параметр        | Смысл                                    | По умолчанию |
|-----------------|------------------------------------------|--------------|
| `LETTER_H`      | высота буквы на сцене, px                | 520          |
| `BRUSH`         | радиус кисти стирания, px                | 40           |
| `WIN_AT`        | доля стёртой пены для победы (0…1)       | 0.90         |
| `WIN_DELAY_GO`  | задержка перед переходом по completeUrl, мс | 1400      |
| `TOWEL_W`       | ширина полотенца, px                     | 150          |

## Как устроено стирание

- Слой пены живёт в отдельном `<canvas>` поверх картинки чистой буквы.
- Движение кисти рисует в нём мягкую круглую маску с режимом
  `globalCompositeOperation = 'destination-out'` — пена исчезает,
  чистая буква проступает снизу.
- Точки указателя интерполируются (шаг ≈ 0.3 радиуса), чтобы на быстром
  движении полоса стирания была сплошной.
- Прогресс считается по уменьшенной копии слоя (48×48, доля непрозрачных
  пикселей к исходной), проверка не чаще раза в 120 мс — дёшево даже на
  слабых планшетах.
- Полотенце догоняет указатель с инерцией (lerp 0.38), наклоняется по
  скорости и слегка «прижимается» во время стирания.
- Звук трения — зацифрованный шум через полосовой фильтр WebAudio,
  громкость зависит от скорости движения; фанфара — четыре синусоиды.

## Событие «буква вытерта» и переход

Когда буква очищена целиком (достигнут порог `WIN_AT` и пена дочищена),
игра сообщает об этом двумя способами:

```js
// 1) событие на window
window.addEventListener('letter:cleaned', function (e) {
  // e.detail = { char: 'А', index: 0, stars: 3, seconds: 12 }
});

// 2) простой колбэк (для старых окружений)
window.onLetterCleaned = function (detail) { ... };
```

Переход после очистки задаётся конфигуратором до загрузки `index.html`:

```js
window.GAME_SETTINGS = { completeUrl: 'done.html?letter={char}&i={index}' };
```

или полем `next` у конкретной буквы в `js/letters.js`
(`next` имеет приоритет над общим `completeUrl`). Плейсхолдеры `{char}`
и `{index}` подставляются автоматически. Если URL задан — победный оверлей
не показывается, через `WIN_DELAY_GO` мс происходит переход
(`window.location.href`). Если URL не задан — оверлей со звёздами и кнопками
«Ещё раз» / «Дальше», как раньше.

## Добавление букв в общий запуск

Единственный конфиг набора — **`1/wipe/js/letters.js`** (путь от корня репозитория).
Редактируйте `window.LETTERS` именно в нём:

```js
{ char: 'Г', foam: 'assets/letters/g_foam.png', clean: 'assets/letters/g_clean.png' },
```

Файлы примера положите в `1/wipe/assets/letters/`. Пути в `foam` и `clean`
считаются от `1/wipe/scene.html`, а не от общего `1/index.html`.
Обе картинки обязательны; размер и положение буквы в паре должны совпадать.

Количество букв не задаётся отдельно: используются все элементы `LETTERS`.
С галочкой «Вкусности» порядок совпадает с массивом, после последней буквы
снова открывается первая. Без галочки и старт, и «Дальше» выбирают из полного
массива, без немедленного повтора предыдущей буквы.

Если новые элементы не появились, проверьте, что изменён именно этот файл,
пути и регистр имён изображений совпадают, и обновите страницу без кеша.
`js/game1.js` не подключён к сцене и не является конфигом активной игры.

Проверки расширенного набора (дополнительные картинки подменяются тестовыми):

```sh
DYNAMIC_LETTERS=1 node 1/wipe/scripts/smoke.js
DYNAMIC_LETTERS=1 RANDOM_ORDER=1 node 1/wipe/scripts/smoke.js
```
