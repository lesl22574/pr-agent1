# Азбука

Единая точка запуска — **`1/index.html`**. Все игровые файлы находятся в папке `1`.
Других файлов `index.html` в репозитории нет.

## Запуск

Из корня репозитория:

```sh
python3 -m http.server 8000 --bind 0.0.0.0 --directory 1
```

Откройте `http://localhost:8000/`.
Для публикации на статическом хостинге используйте папку `1` целиком.

## Занятия

Выберите занятие справа и нажмите «Играть» (или «Продолжить»):

- **Изучение букв** — карточки и шарики. После шариков открывается следующая
  буква изучения. Рисование запускается отдельно из меню.
- **Рисование букв** — занятие из второй части: стирание пены полотенцем.
  В комплекте три буквы: А, Б и В; «Дальше» выбирает букву согласно флажку «Вкусности».
- **Чтение** — составление слов из букв.

Домик возвращает в общее меню. Прогресс изучения и чтения сохраняется,
если браузер разрешает локальное хранилище.
Флажок «Вкусности» задаёт порядок букв в изучении и рисовании:
включён — по порядку, выключен — случайный выбор без повторения предыдущей буквы.
Прогресс последовательного изучения сохраняется отдельно от случайной игры.

Меню использует `frankc.ttf`, рамку `candybutt1 (7)  (1) (2).png` и
пейзаж `assets/menu-bg.svg`, воссозданный по приложенному образцу.
Основной код находится в `1/js`, занятие с полотенцем — в `1/wipe`.

## Полноэкранные фоны и музыка меню

Фон заполняет всё окно (`background-size: cover`), сохраняет пропорции,
лишнее по краям обрезается. Размер игровых элементов подстраивается отдельно,
чтобы кнопки и карточки оставались доступны при разных пропорциях экрана.

Добавьте файлы (сейчас в репозитории их нет):

- `1/assets/img/51.jpg` — фон изучения букв, шариков и чтения.
- `1/assets/audio/Veselaya_karusel.mp3` — зацикленная мелодия стартового меню.

Имена и регистр должны совпадать. До добавления `51.jpg` используется пейзаж меню.
Для рисования используется существующий `1/wipe/assets/bg.png`.

Музыка меню играет с громкостью 50 % и останавливается при переходе к занятию
и при скрытии вкладки. Кнопка звука в рисовании скрыта.
Если браузер ограничивает автозапуск аудио, воспроизведение повторно запускается
при первом нажатии в меню. Отсутствие файла музыки не мешает работе игры.


## Ассет кнопки «В меню»

Положите готовое изображение кнопки по пути **`1/assets/img/btn-home.png`**.
Оно используется в изучении, чтении и рисовании. Рисунок отображается целиком,
с сохранением пропорций, без дополнительной рамки (область кнопки — 66×66).
До добавления файла остаётся стандартный значок домика; переход в меню работает
в обоих вариантах. Название файла и регистр должны совпадать.


## SDK Яндекс Игр и рекламные паузы

SDK, уровни и основной код подключаются с `defer` в указанном порядке,
чтобы инициализация игры не опережала загрузку SDK. При инициализации читается
`ysdk.environment.i18n.lang` (`window.YANDEX_LANGUAGE`, запасное значение — `ru`).
Текущая версия одноязычная: `window.GAME_LANGUAGE` и язык документа — `ru`.
`LoadingAPI.ready()` вызывается после получения SDK, в том числе при его позднем ответе.

В рисовании сразу после очистки буквы родительская игра запускает межстраничную
рекламу. Фанфара, озвучка буквы и экран результата запускаются после закрытия
рекламы либо после сообщения о её недоступности. SDK может не показать рекламу
из-за ограничений частоты; игра в таком случае продолжится.

Рекламная пауза выключает музыку меню, текущую озвучку и звук встроенного
рисования. Закрытие или ошибка рекламы снимает паузу, возобновляет речевой
синтез и WebAudio. При отклонении `Audio.play()` используется речевая озвучка.
Настройка звука игрока при этом сохраняется.

Дополнительная проверка порядка «реклама → звук/результат»:

```sh
AD_BRIDGE=1 node 1/wipe/scripts/smoke.js
```


## Отключение заглушек

В `1/js/settings.js` настройка `showPlaceholders: false` отключает заглушки
в изучении букв (уже установлена по умолчанию). В основной картинке не появляются
emoji и временная текстовая буква во время ожидания. Если основная картинка
не найдена, проверяется настоящая карточка этой буквы. Если нет и её,
после проверки показывается сама буква задания, чтобы экран не оставался пустым.
Карточки выбора скрыты на время проверки ассета, общий запасной фон `card.*`
не загружается. Если индивидуального ассета карточки нет, появляется обычная
кнопка с буквой, чтобы задание оставалось доступным.
Для возврата прежнего поведения задайте `showPlaceholders: true`.


## Активность окна и звуки

После инициализации SDK игра подписывается на `game_api_pause` и
`game_api_resume`. Дополнительно используются `visibilitychange` и события
фокуса окна — это работает и при запуске вне Яндекс Игр. Переход фокуса
внутрь iframe рисования не считается уходом из игры.

При потере активности или показе рекламы приостанавливаются музыка меню,
HTMLAudio-озвучка, речевой синтез и WebAudio рисования. Музыка и текущая
запись продолжаются с сохранённой позиции; если за время паузы сменилось
задание, воспроизводится актуальная озвучка. WebAudio приостанавливается
вместе с контекстом, а не только изменением громкости.

Причины паузы учитываются независимо: например, закрытие рекламы в неактивном
окне не включает звук. Восстановление происходит после возврата активности,
закрытия рекламы и снятия паузы SDK. Пользовательское отключение звука
сохраняется. Продолжение результата рисования после рекламы также ожидает
возврата активности.


## Переходы после рекламы

Возврат из рекламного iframe дополнительно подтверждается настоящим нажатием
или нажатием клавиши внутри игры: это снимает оставшуюся паузу фокуса/SDK,
если WebView не доставил событие возврата. Во время открытой рекламы, а также
в скрытой вкладке такое восстановление не выполняется.
Отложенные рекламные продолжения привязаны к сессии занятия: результат старого
рисования не может изменить экран заново запущенного изучения.

В шариках используется аудиофайл буквы (`letterSound` в `1/js/levels.js`),
а если отдельной записи нет — запись текущего уровня (`sound`). Речевой синтез
остаётся резервным вариантом при отсутствии аудиофайла. Это также касается
озвучки при нажатии на шарик. Последний шарик больше не прерывается немедленным
запуском другой реплики.


### Озвучка чтения после перехода из других режимов

Для чтения действует то же восстановление активности после рекламы, что и для
остальных режимов. При запуске чтения останавливается предыдущая озвучка.
Отложенные рекламные продолжения другого режима не меняют текущее задание.

Порядок поиска записи слова: поле `sound` записи в `READ_WORDS`, затем `sound`
уровня с таким же словом, затем `assets/audio/words/<слово>.mp3`.
При отсутствии файла используется речевой синтез. Реплика синтеза сохраняется
до завершения, чтобы переход между режимами не прерывал её из-за освобождения
объекта браузером. Буквы читаются через `letterSound` или `sound` уровня.

Автотесты проверяют вход в чтение после рекламы из рисования и изучения букв,
включая задержанный SDK resume, начальную озвучку, букву, повтор слова
и резервный речевой синтез.


## Вступительная озвучка рисования

Положите общий аудиофайл инструкции по пути **`1/assets/audio/wipe-start.mp3`**.
Например, запишите фразу «Возьми полотенце и вытри букву» без названия
конкретной буквы: один файл используется для А, Б и В.

Запись включается после загрузки картинок буквы при входе в рисование,
переходе «Дальше» и нажатии «Ещё раз». При отсутствии файла используется
речевая фраза с текущей буквой. Вступление управляется общими паузами звука,
останавливается при выходе из режима и перед рекламой после очистки.
