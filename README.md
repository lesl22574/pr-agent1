# Азбука

Единая точка запуска — **`1/index.html`**. Все игровые файлы находятся в папке `1`.
Других файлов `index.html` в репозитории нет.

## Запуск

Из корня репозитория:

```sh
python3 -m http.server 8000 --bind 0.0.0.0 --directory 1
```

Откройте `http://localhost:8000/`.
Для публикации на статическом хостинге используйте папку `1` целиком.

## Занятия

Выберите занятие справа и нажмите «Играть» (или «Продолжить»):

- **Изучение букв** — карточки и шарики. После шариков открывается следующая
  буква изучения. Рисование запускается отдельно из меню.
- **Рисование букв** — занятие из второй части: стирание пены полотенцем.
  В комплекте три буквы: А, Б и В; «Дальше» выбирает букву согласно флажку «Вкусности».
- **Чтение** — составление слов из букв. На подложке виден полупрозрачный
  образец слова; перенесённые буквы закрывают подсказки. Тигрёнок убран.

Домик возвращает в общее меню. Прогресс изучения и чтения сохраняется,
если браузер разрешает локальное хранилище.
Флажок «Вкусности» задаёт порядок букв в изучении и рисовании:
включён — по порядку, выключен — случайный выбор без повторения предыдущей буквы.
Прогресс последовательного изучения сохраняется отдельно от случайной игры.

Меню использует `frankc.ttf`, рамку `candybutt1 (7)  (1) (2).png` и
пейзаж `assets/menu-bg.svg`, воссозданный по приложенному образцу.
Основной код находится в `1/js`, занятие с полотенцем — в `1/wipe`.

## Полноэкранные фоны и музыка меню

Фон заполняет всё окно (`background-size: cover`), сохраняет пропорции,
лишнее по краям обрезается. Размер игровых элементов подстраивается отдельно,
чтобы кнопки и карточки оставались доступны при разных пропорциях экрана.

Добавьте файлы (сейчас в репозитории их нет):

- `1/assets/img/51.jpg` — фон изучения букв, шариков и чтения.
- `1/assets/audio/Veselaya_karusel.mp3` — зацикленная мелодия стартового меню.

Имена и регистр должны совпадать. До добавления `51.jpg` используется пейзаж меню.
Для рисования используется существующий `1/wipe/assets/bg.png`.

Музыка меню играет с громкостью 50 % и останавливается при переходе к занятию
и при скрытии вкладки. Кнопка звука в рисовании скрыта.
Если браузер ограничивает автозапуск аудио, воспроизведение повторно запускается
при первом нажатии в меню. Отсутствие файла музыки не мешает работе игры.


## Ассет кнопки «В меню»

Положите готовое изображение кнопки по пути **`1/assets/img/btn-home.png`**.
Оно используется в изучении, чтении и рисовании. Рисунок отображается целиком,
с сохранением пропорций, без дополнительной рамки (область кнопки — 66×66).
До добавления файла остаётся стандартный значок домика; переход в меню работает
в обоих вариантах. Название файла и регистр должны совпадать.


## Озвучка и аудиоассеты

Актуальная настройка всех записей, пути и тексты реплик:
**[AUDIO_ASSETS.md](AUDIO_ASSETS.md)**.

По умолчанию игра использует MP3 (`speechFallback: false`), а не браузерную
генерацию речи. Для запуска новых реплик добавьте аудиофайлы по инструкции.
Проверка наличия: `node scripts/check_audio_assets.js`.

- Шарики: общая инструкция, запись буквы за верный ответ, общий неверный ответ.
- Рисование: общая инструкция `1/assets/audio/wipe-start.mp3` в начале;
  после очистки — реклама и фанфара без речи.
- Чтение: общая инструкция в начале, запись выбранной верной буквы,
  общий неверный ответ, после сборки — реклама и затем полная запись слова.
- Выбор карточек: собственная запись уровня либо общая инструкция.

## SDK Яндекс Игр и активность окна

При инициализации читается `ysdk.environment.i18n.lang`;
для одноязычной игры активным остаётся `ru`.
Обрабатываются `game_api_pause`, `game_api_resume`, видимость и фокус окна.
Реклама и неактивное окно приостанавливают звуки, а возврат восстанавливает их.
Отложенные рекламные продолжения не переключают новое занятие на старое.

## Заглушки изображений

`showPlaceholders: false` в `1/js/settings.js` относится только к изображениям.
Во время загрузки картинки не показываются emoji и временная буква.
Если основной файл не найден, проверяется карточка этой буквы; если нет и её,
показывается сама буква задания. На звуки эта настройка не влияет.


## Свои файлы карточек в изучении букв

В `1/js/levels.js`, массив `LEVELS`, у нужной буквы задайте `cardImage`:

```js
{
  letter: 'А',
  cardImage: 'assets/img/cards/my-letter-a.webp',
  image: 'assets/img/ananas.png',
  // остальные поля уровня сохраняются
}
```

Путь указывается относительно `1/index.html`. Имя файла произвольное,
расширение указывается явно (PNG, JPG, WebP и другие форматы браузера).
Картинка должна содержать готовую карточку вместе с буквой: текст поверх
не рисуется. `cardImage` используется для карточек выбора в изучении букв,
в том числе когда эта буква появляется среди вариантов на другом уровне.
`image` — отдельная большая картинка предмета на доске; это другая настройка.

При `cardImage: null` сохраняется автоматический поиск
`assets/img/cards/<БУКВА>.png`, затем `.jpg`, `.webp`.
Если свой файл не загрузился, также используется стандартный поиск.
Настройки режима чтения эта опция не меняет.


Отдельные звуки верного и неверного выбора карточек: `audio.chooseCorrect`
и `audio.chooseWrong` в `1/js/settings.js`. Реклама запрашивается только при верном выборе карточки; запись верного
ответа звучит после рекламы, затем показывается салют и открываются шарики. При неверном выборе рекламы нет. Подробности и пути — в `AUDIO_ASSETS.md`.


Салют после верной карточки работает без графических ассетов. Для его
зацикленного звука добавьте `1/assets/audio/common/fireworks.mp3`.
Длительность задаётся `fireworksDuration` в `1/js/settings.js` (по умолчанию 4000 мс).
