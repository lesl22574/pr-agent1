# Судоку — нативное Android‑приложение

Веб‑игра на HTML + JS превращена в полноценное мобильное приложение на **Kotlin** и **Jetpack Compose**.
Дизайн, правила и ощущение интерфейса сохранены: тёплая бумажная палитра, бирюзовый акцент, серифные заголовки,
поле 9×9 с подсветкой строки и квадрата, заметки, подсказки, отмена хода, таймер и три уровня сложности.

## Что в репозитории

| Путь | Описание |
| --- | --- |
| `android/` | Нативное Android‑приложение (Gradle + Kotlin + Compose) |
| `web/index.html` | Исходная веб‑версия, с которой сделан перенос |
| `index.html` | Ранняя версия веб‑игры |

## Возможности приложения

- Генерация головоломки прямо на устройстве — с гарантией единственного решения.
- Три уровня сложности: легко (42 подсказки), средне (35), сложно (29).
- Режим заметок, три подсказки на игру, отмена хода (до 100 шагов), стирание.
- Подсчёт ошибок (три ошибки — игра завершена), прогресс и таймер.
- Переключение языка RU / EN прямо в шапке, без перезапуска.
- Автосохранение: закрыл приложение — вернулся к той же головоломке, таймеру и количеству ошибок.
- Полностью светлая тема и три раскладки: телефон в портретной ориентации, телефон боком и планшет
  (широкий трёхколоночный вид, как в веб-версии).
- Никаких разрешений и сетевых запросов: интернет приложению не нужен.

## Технологии

- Kotlin 2.0.21, Jetpack Compose (Material 3), Compose BOM 2024.10.01
- `minSdk 24`, `targetSdk 35`, `compileSdk 35`, JVM 17
- Чистая архитектура правил: игровая логика не зависит от Android и покрыта unit‑тестами
- Хранение состояния — `SharedPreferences` и компактный текстовый формат (`GameCodec`)

## Сборка

### Android Studio (самый простой путь)

1. Установите Android Studio (Ladybug или новее) с JDK 17.
2. `File → Open…` и выберите папку `android/`.
3. Дождитесь синхронизации Gradle (Studio подставит Gradle 8.9 и создаст wrapper).
   Если Studio попросит добавить Gradle wrapper — согласитесь: это одно нажатие,
   версия уже указана в `android/gradle/wrapper/gradle-wrapper.properties`.
4. Нажмите **Run ▶** — приложение соберётся и установится на устройство или эмулятор.

### Командная строка

```bash
cd android
gradle wrapper --gradle-version 8.9   # один раз, если нужен ./gradlew
./gradlew :app:assembleDebug
```

Готовый файл появится в `android/app/build/outputs/apk/debug/`.

### Тесты

```bash
cd android
./gradlew :app:testDebugUnitTest
```

Тесты проверяют генератор (валидность и единственность решения, количество подсказок), все игровые ходы,
подсчёт ошибок, победу и поражение, таймер, смену сложности и сохранение/восстановление партии.
Эти же тесты запускаются в GitHub Actions (`.github/workflows/android.yml`) вместе со сборкой debug‑APK.

### Готовый APK без локальной сборки

Workflow **Android** собирает приложение при каждом изменении в `android/`:
откройте вкладку **Actions → Android → последний запуск** и скачайте артефакт `sudoku-debug-apk`
(внутри — устанавливаемый `app-debug.apk`). Артефакт доступен только владельцу репозитория.

## Публикация в Google Play

1. Создайте ключ подписи:
   ```bash
   keytool -genkeypair -v -keystore sudoku-release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias sudoku
   ```
2. Добавьте настройки подписи в `android/app/build.gradle.kts` (или через переменные окружения в CI).
3. Соберите бандл: `./gradlew :app:bundleRelease` — файл `.aab` лежит в `android/app/build/outputs/bundle/release/`.
4. Загрузите его в Play Console, заполните карточку, скриншоты и политику конфиденциальности
   (данные не собираются, разрешений нет — это стоит указать явно).

Перед публикацией удобно поднять `versionCode` и `versionName` в `android/app/build.gradle.kts`.

## Что уже проверено

- Компиляция всего приложения (Kotlin + Compose + ресурсы) и сборка debug‑APK — в GitHub Actions.
- 21 unit‑тест игрового ядра на JVM: генерация и уникальность решения, все ходы, заметки, подсказки,
  отмена, поражение, победа, следующий уровень, таймер, смена сложности, сохранение и восстановление.
- Доступность: у каждой клетки есть подпись для TalkBack, у кнопок — описания, размеры нажатий не меньше 40 dp.

## Чем нативная версия отличается от веб

- Вместо DOM и `localStorage` — Compose и `SharedPreferences`; сохранение работает так же незаметно.
- Генерация и проверка единственности решения выполняются на устройстве в фоновом потоке,
  поэтому интерфейс не подвисает даже на слабых телефонах.
- Убраны Яндекс SDK, реклама и счётчики — они не нужны вне площадки Yandex Games.
  Если понадобится монетизация, проще всего добавить рекламный SDK (например, AdMob) в `GameViewModel`
  между победами, как это было сделано в веб‑версии.
- Добавлены мелочи, которых ждут от мобильного приложения: сохранение языка, работа в фоне с остановкой
  таймера, доступные подписи клеток для TalkBack, иконка и адаптивная вёрстка для планшетов.
