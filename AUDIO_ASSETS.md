# Настройка аудиоассетов

Все пути ниже указаны **от корня репозитория**. На хостинг загружайте папку
`1` целиком. Названия файлов, регистр и буква `ё` должны совпадать.
Новые записи нужно добавить самостоятельно: код подключает их, но не создаёт MP3.

По умолчанию `speechFallback: false` в `1/js/settings.js`: браузерная генерация
не используется, в том числе при отсутствии записи. Пропуск файла не заменяется
инструкцией из другого режима. Заглушки изображений от звука независимы.

## 1. Общие записи

| Файл | Когда включается | Рекомендуемое содержимое |
| --- | --- | --- |
| `1/assets/audio/common/pop-start.mp3` | Начало каждого уровня с шариками | «Лопай шарики с нужной буквой» |
| `1/assets/audio/common/read-start.mp3` | Начало каждого уровня чтения | «Составь слово из букв» |
| `1/assets/audio/wipe-start.mp3` | Начало каждого уровня рисования, «Дальше», «Ещё раз» | «Возьми полотенце и вытри букву» |
| `1/assets/audio/common/wrong.mp3` | Неверный шарик или неверная буква в чтении | Короткий звук либо «Попробуй ещё» |
| `1/assets/audio/common/choose-correct.mp3` | Верная карточка после рекламы | Короткий звук либо «Молодец» |
| `1/assets/audio/common/fireworks.mp3` | Зациклен на время салюта после верной карточки | Звук салюта без речи |
| `1/assets/audio/common/choose-wrong.mp3` | Неверная карточка в изучении букв | Короткий звук либо «Попробуй ещё» |
| `1/assets/audio/common/choose-start.mp3` | Начало выбора карточек, только если у уровня нет своей записи | «Выбери нужную букву» |

Для каждого типа начала используется **один общий файл**, без названия
конкретной буквы или слова. Не записывайте инструкцию карточек в файлы букв.
После очистки буквы в рисовании речи нет: остаются рекламная пауза,
фанфара и экран результата.

## 2. Произношение букв

Стандартный путь: **`1/assets/audio/letters/<БУКВА>.mp3`**, например:

```text
1/assets/audio/letters/Б.mp3
1/assets/audio/letters/Д.mp3
1/assets/audio/letters/Ё.mp3
```

В каждом файле — **только соответствующая буква**, без инструкции и названия
предмета. Эти записи используются при верном нажатии на шарик или букву чтения.
Нужны все буквы из `LEVELS` и из слов `READ_WORDS` в `1/js/levels.js`.

Для буквы А уже задан отдельный существующий файл `assets/audio/a_l.mp3`.
Путь можно заменить полем `letterSound` в `LEVELS`:

```js
{ letter: 'А', letterSound: 'assets/audio/letters/А.mp3', /* остальные поля */ }
```

Если `letterSound` не указан, используется стандартный путь с заглавной буквой.
Поле `sound` у уровня карточек **не используется** для произношения буквы.

## 3. Полная озвучка собранного слова

Стандартный путь: **`1/assets/audio/words/<слово>.mp3`**, слово строчными буквами.
Для текущего набора:

```text
1/assets/audio/words/дом.mp3
1/assets/audio/words/кот.mp3
1/assets/audio/words/сок.mp3
1/assets/audio/words/мак.mp3
1/assets/audio/words/лук.mp3
1/assets/audio/words/мяч.mp3
1/assets/audio/words/ёлка.mp3
1/assets/audio/words/кошка.mp3
1/assets/audio/words/арбуз.mp3
1/assets/audio/words/тигр.mp3
1/assets/audio/words/ягода.mp3
```

Запишите **слово целиком**, не побуквенное чтение и не инструкцию.
После сборки запрашивается межстраничная реклама. Слово включается
**после закрытия рекламы** (либо сообщения SDK о её недоступности);
в начале уровня звучит только `read-start.mp3`.
Переход к следующему слову ждёт окончания записи, поэтому длинный файл
не обрывается фиксированным таймером.
Рекомендуется короткая запись без тишины в начале и конце.

Файл для каждого слова задаётся явно в **`1/js/levels.js`**, в массиве
**`READ_WORDS`**, поле **`sound`**. Можно указать любое имя, независимо от слова:

```js
{ word: 'дом', sound: 'assets/audio/words/dom.mp3' }
{ word: 'кот', sound: 'assets/audio/words/voice-02.mp3' }
```

Путь задаётся от `1/index.html`. Поле влияет на озвучку собранного слова; стартовая инструкция чтения настраивается отдельно.

## 4. Существующие записи выбора карточек

Поле `sound` у записи `LEVELS` остаётся отдельной озвучкой уровня карточек.
Существующие файлы не заменяются. Если `sound: null`, используется общая
инструкция `common/choose-start.mp3`, а не браузерный синтез.

## 5. Замена путей общих файлов

В `1/js/settings.js` можно указать любые относительные пути **от `1/index.html`**:

```js
audio: {
  popStart: 'assets/audio/common/pop-start.mp3',
  readStart: 'assets/audio/common/read-start.mp3',
  wipeStart: 'assets/audio/wipe-start.mp3',
  wrong: 'assets/audio/common/wrong.mp3',
  fireworks: 'assets/audio/common/fireworks.mp3',
  chooseCorrect: 'assets/audio/common/choose-correct.mp3',
  chooseWrong: 'assets/audio/common/choose-wrong.mp3',
  chooseStart: 'assets/audio/common/choose-start.mp3'
}
```

Если ключ не указан, применяется путь из таблицы. Значение `null` отключает
конкретную запись, когда `speechFallback: false`.

## 6. Проверка перед публикацией

Из корня репозитория запустите:

```sh
node scripts/check_audio_assets.js
```

Скрипт перечисляет недостающие файлы с учётом текущих настроек и набора уровней.
До добавления новых записей сообщения о недостающих файлах ожидаемы.
После добавления проверьте игру локально, затем на площадке:

1. Шарики: инструкция → верный шарик (буква) → неверный шарик (общий звук).
2. Рисование: общая инструкция → очистка → реклама → фанфара без речи.
3. Чтение: общая инструкция → верная буква → неверная буква → сборка слова
   → реклама → полная запись слова → следующий уровень.
4. Повторите переходы после рекламы и переключения окна.

Реклама и неактивное окно приостанавливают записи; общая громкость и настройка
звука сохраняются. Проверка наличия файлов не заменяет проверку их содержимого
и слышимого воспроизведения в браузере.

Если браузер после рекламы ограничивает запуск записи (`NotAllowedError`),
игра сохраняет её для повторного запуска по нажатию в игровом поле, не
пропуская слово. Выход в меню отменяет отложенную озвучку старого уровня.


## Ответы на карточках изучения букв

Отдельные пути задаются в `1/js/settings.js`, внутри `audio`:

```js
chooseCorrect: 'assets/audio/common/choose-correct.mp3',
chooseWrong: 'assets/audio/common/choose-wrong.mp3'
```

Укажите свои имена файлов, если нужно. Обе записи общие для всех букв, но
используются **только при выборе карточки**, а не в шариках и чтении.
После верной карточки сразу запрашивается реклама, затем включается
`chooseCorrect`, затем на 4 секунды показывается салют, после него открываются шарики.
При неверной карточке звучит `chooseWrong`, реклама не запрашивается.
Выход в меню отменяет отложенную озвучку и переход старого уровня.
Если запись не найдена, звук отключён или `chooseCorrect: null`,
после рекламной паузы открываются шарики без ожидания записи.
Общий неверный ответ шариков и чтения по-прежнему задаётся ключом `wrong`.


## Салют после правильного выбора карточки

Порядок: правильная карточка → реклама → озвучка `chooseCorrect` → салют → шарики.
Неправильный ответ салют не запускает. Эффект нарисован кодом, изображения
для него не требуются. Подложка — полупрозрачная фиолетовая.

Добавьте **`1/assets/audio/common/fireworks.mp3`** — звук без речи, подходящий
для бесшовного повторения. Во время салюта он зациклен; по завершении или
при выходе в меню останавливается и сбрасывается в начало. Если файл не добавлен,
визуальный эффект продолжит работать без звука.

Настройки в `1/js/settings.js`:

```js
fireworksDuration: 4000, // миллисекунды активного показа
// внутри audio:
fireworks: 'assets/audio/common/fireworks.mp3'
```

При переключении окна или рекламной паузе анимация, отсчёт длительности и звук
приостанавливаются, затем продолжаются. Отключение звука не убирает сам салют.
Домик возвращает в меню и отменяет переход к шарикам. Для системной настройки
уменьшения движения вместо анимации показываются статичные искры.
